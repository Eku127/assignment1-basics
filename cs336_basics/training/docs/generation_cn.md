# 文本生成（Inference）与解码策略指南

本文档旨在详细解释如何使用训练好的 Transformer 模型进行文本生成（也称为推理或解码），并深入探讨控制生成文本质量的几种核心解码策略。

---

## 1. 概述

训练语言模型的最终目的是让它能够生成新的、连贯的文本。这个过程是**自回归（Autoregressive）**的：
1.  我们为模型提供一个初始的文本片段，称为**提示（Prompt）**。
2.  模型根据这个提示，预测下一个最可能的词（Token）。
3.  我们将这个新生成的词追加到提示的末尾，形成一个新的、更长的序列。
4.  模型再以这个新序列为输入，重复第2步和第3步，一个词一个词地“写”出完整的文本。

`generate.py` (一个假设的生成脚本) 的任务就是加载一个训练好的模型检查点（checkpoint），并执行上述的自回归生成过程。

---

## 2. 如何使用（示例）

一个典型的生成脚本会通过命令行参数来控制，允许用户灵活地指定模型、输入和生成策略。

```bash
python cs336_basics/generation/generate.py \
    --checkpoint /path/to/my_model_checkpoint.pt \
    --prompt "Once upon a time, in a land far away," \
    --max_new_tokens 150 \
    --strategy "top_p" \
    --temperature 0.8 \
    --top_p 0.92
```

-   `--checkpoint`: 指向训练好的模型检查点文件。
-   `--prompt`: 生成文本的起始句子。
-   `--max_new_tokens`: 指定模型需要生成的新词数量。
-   `--strategy`: 选择使用的解码策略（如 `greedy`, `temperature`, `top_k`, `top_p`）。
-   后续参数（`--temperature`, `--top_p`等）是特定策略所需的超参数。

---

## 3. 解码策略详解

模型在前向传播后，会为词汇表中的每个词输出一个原始分数（Logits）。我们需要将这些分数转换成概率分布，并根据这个分布**选择**下一个词。如何选择，就是解码策略的核心。不同的策略会极大地影响生成文本的质量、创造性和连贯性。

### a. 贪心采样 (Greedy Sampling)

这是最简单、最直接的解码策略。

-   **工作原理**: 在每一步，总是选择概率最高的那个词作为下一个词。
-   **优点**:
    -   实现简单，计算速度快。
    -   输出是确定的（对于相同的输入，总能得到相同的结果）。
-   **缺点**:
    -   极其容易生成重复、呆板、缺乏变化的文本。
    -   经常会陷入重复的循环中（例如，"I think I think I think..."）。
    -   因为它只看眼前最优解，可能会错过全局上更好的句子结构。
-   **适用场景**: 主要用于需要确定性输出的评估任务，不适合用于创造性文本生成。

### b. 温度采样 (Temperature Sampling)

温度采样通过一个名为**温度（T）**的参数来控制采样的随机性。

-   **工作原理**: 在应用 Softmax 函数之前，先将所有的 Logits 除以温度 `T`。
    
    $$ P_i = \text{Softmax}\left(\frac{\text{logits}_i}{T}\right) $$
    
-   **温度 `T` 的影响**:
    -   **`T > 1` (高温)**: 降低了 Logits 之间的差距，使得概率分布更**平滑**。模型会变得更大胆、更有创造力，有更高几率选择不那么常见的词。但过高的温度会导致生成无关的胡言乱语。
    -   **`0 < T < 1` (低温)**: 扩大了 Logits 之间的差距，使得概率分布更**尖锐**。模型会变得更保守、更自信，倾向于选择它认为最可能的词。
    -   **`T` → 0**: 效果趋近于贪心采样。
    -   **`T = 1`**: 标准的 Softmax 采样。
-   **优点**: 提供了一个简单而有效的旋钮，用于在“保守求稳”和“大胆创新”之间进行权衡。
-   **缺点**: 单纯使用温度采样时，即使概率极低的词（可能是噪声或错误）也有机会被选中，有时会损害文本的连贯性。

### c. Top-k 采样

Top-k 采样通过限制候选词的数量来避免从低概率词中采样。

-   **工作原理**:
    1.  从模型得到所有词的概率分布。
    2.  只选择其中概率最高的 `k` 个词。
    3.  将这 `k` 个词的概率进行归一化（使它们的总和为1）。
    4.  从这个新的、更小的概率分布中进行采样。
-   **优点**:
    -   有效排除了大量不相关、不合理的词，生成的文本通常比温度采样更连贯。
-   **缺点**:
    -   候选池的大小是**固定**的 (`k`)。这在某些情况下不理想：当模型非常确定时（分布很尖锐），`k` 个候选可能太多；而当模型很不确定时（分布很平滑），`k` 个候选可能又太少，会扼杀多样性。

### d. Top-p (核) 采样 (Nucleus Sampling)

Top-p 采样是 Top-k 的一种改进，它使用一个**动态的**候选词集。

-   **工作原理**:
    1.  将所有词按概率从高到低排序。
    2.  从概率最高的词开始，依次累加它们的概率，直到总和超过一个预设的阈值 `p`（例如 `p=0.9`）。
    3.  所有被累加过的词构成一个“核”（Nucleus），这个核就是我们的候选词集。
    4.  与 Top-k 类似，对这个“核”中的词进行概率归一化，然后从中采样。
-   **优点**:
    -   **自适应**: 候选集的大小是动态的。当模型对下一个词很确定时（分布尖锐），候选集可能只有几个词；当模型不确定时（分布平滑），候选集会包含更多的词。
    -   这在多样性和连贯性之间取得了非常好的平衡，通常被认为是当前效果最好的解码策略之一。
-   **缺点**:
    -   概念上比 Top-k 稍复杂。`p` 值也需要调整。

在实践中，通常会将 Top-p 或 Top-k 与温度采样结合使用，以获得最佳的生成效果。
